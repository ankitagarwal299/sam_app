Kanban Board

Visual pipeline. Drag or click to move POs across columns. Great workflow visibility. Less detail per PO — no room for 10+ columns. Best for smaller datasets.

Compact table on left, full PO detail on right when selected. Actions in the detail panel. Good when POs have lots of metadata. Click a row to see everything without a modal.

Single table, but rows grouped under status headers. Collapse/expand each group. Shows totals per group. Visual hierarchy without tabs. Right actions per group context.

Quick comparison

  • Kanban — Best visual workflow, but loses table detail (no 10+ columns). Good if PO count is small.
  • Master-Detail — Best for data-heavy POs. Table stays compact, detail panel shows everything. Actions feel contextual.
  • Grouped Table — Best of both worlds: full table columns + clear status grouping. No tabs, no detail panel. Totals per status.

Or combine them

  • You could use Grouped Table (C) + click-to-expand detail row instead of a side panel
  • Or use the previous flat table with filter pills if your manager prefers simplicity
