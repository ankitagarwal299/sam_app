Why this matters

  • The PRD's "People" tab has 3 distinct views (Hiring Requests, Approved Team, Monthly Grid)
  • The monthly planning grid needs 12+ columns of financial data
  • Finance sees more metadata columns than Budget Owner
  • Both roles need the same tabs, but different sub-views within them

Recommendation

  • Option C (Hybrid) handles the PRD's complexity best
  • Top tabs keep expense categories visible at all times
  • Sub-nav handles the multiple views within each category
  • Role determines which sub-views and actions appear
